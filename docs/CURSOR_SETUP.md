# Cursor setup

1. Open Cursor.
2. File → Open Folder → select the cloned `Nova-AI` repo.
3. Cursor reads `skills/` automatically as project rules.
4. Add more agents in `agents/`, tasks in `tasks/`.

The sticky skill `skills/story-teller-weighted-dialogue/SKILL.md` is live for every agent in this repo — weighted dialogue morph for adventure choice stories (feminize / genderbend / submissive play, four-slot choices, hidden checks). Full D&D example: `skills/story-teller-weighted-dialogue/examples/dnd-thistle-vale-vault-interrogation.md`.
