# Cursor setup

1. Open Cursor.
2. File → Open Folder → select the cloned `Nova-AI` repo.
3. Cursor reads `skills/` automatically as project rules.
4. Add more agents in `agents/`, tasks in `tasks/`.

The sticky skill `skills/story-teller-weighted-dialogue/SKILL.md` is live for every agent in this repo — weighted dialogue morph for **roleplay and D&D dialogue adventures** (feminize / genderbend / submissive play, four-slot choices, hidden checks). Two modes in one skill: `start rp` or `start dnd`. Full D&D example: `skills/story-teller-weighted-dialogue/examples/dnd-ren-vale-vault-interrogation.md`.
