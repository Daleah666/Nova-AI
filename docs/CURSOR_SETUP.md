# Cursor setup

1. Open Cursor.
2. File → Open Folder → select the cloned `Nova-AI` repo.
3. Cursor reads `skills/` as project skills. Flagship: `skills/bot-maker/` — **character first**, then bot wrapping, avatar notes, optional RPG. Finished people go in `characters/<slug>/`.
4. Add more agents in `agents/`, tasks in `tasks/`.
5. Optional rule: `.cursor/rules/bot-maker.mdc` points agents at the skill when you ask for a bot, character, NPC, persona, or text-adventure protagonist.
