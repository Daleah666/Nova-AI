Easy image editor

Type what you want to see, then press Generate. This uses the same Grok picture API as My Hub. Connect directly with your xAI key, or ask the Hub bridge to do it if My Hub is already running.

How to connect

Only needed for Direct API, and only if .env does not already have XAI_API_KEY. The key stays on this computer.

Leave this empty to make a new picture. Choose a PNG, JPEG, or WebP if you want Grok to change a picture you already have.
