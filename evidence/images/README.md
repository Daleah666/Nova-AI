# Image vault

This folder is the anti-lie shelf.

Cursor and Codex both copy every incoming screenshot or reference image here before talking about pixels.

## Naming

`YYYY-MM-DD-HHMMSS-short-name.ext`

Example: `2026-09-18-051830-side-overlay-bar.png`

## Empty on purpose

If this folder has only this README, no image has been ingested in this branch yet.
That means no agent in this workspace has a picture to look at.
