                  Install The Hub

                  Best: the Chrome extension

                  1. Unzip the The Hub extension file Claude sent you and double-click INSTALL.bat.
                  2. On chrome://extensions, switch on Developer mode and click Load unpacked, then pick the folder.
                  3. Click the Hub's toolbar button, copy the pairing code, and paste it in Settings → Chrome extension.
